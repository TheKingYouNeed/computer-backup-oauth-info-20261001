# Privacy policy

Updated 1 October 2026. This configuration is for the account owner's personal use.

## Google account data

The locally running tools use Google Drive permissions to create, read and manage backup repository files in the owner's Drive. OAuth tokens are stored locally with restricted Windows file permissions. The backup configuration does not send data or tokens to this website.

## Storage and sharing

Backup contents are stored in the owner's Google Drive and controlled by the owner's account permissions. The configuration does not publish backup contents or share them with other users. Google provides the storage and account services. The backup is configured without a separate backup passphrase at the owner's request.

## Control

The owner can stop the local scheduled task, revoke the desktop client's access in Google Account settings, and manage or delete backup files in Drive. Revoking access stops subsequent backups. No public users or customer accounts are supported.

## This website

These static pages contain setup information only. They have no forms or analytics added by this configuration. The hosting provider may keep normal hosting access logs.
