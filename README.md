# Personal desktop backup

This is a personal-use desktop configuration for backing up the owner's computer to the owner's Google Drive account using restic and rclone.

The backup runs on the owner's computer. It uploads file data directly to Google Drive and keeps versioned recovery snapshots. This website does not provide a public backup service, accept sign-ups, host backup files, or request Google access.

Google authorization happens through Google's own consent screen for a desktop client controlled by the account owner.
